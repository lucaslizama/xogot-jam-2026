# Sound credits

All sound in this game comes from Kenney's asset packs, released under
Creative Commons Zero. CC0 places them in the public domain: no attribution is
required and none is owed. They are credited here anyway, because knowing where
something came from is worth more than the licence demanding it.

- Impact Sounds, Kenney, CC0. https://kenney.nl/assets/impact-sounds
- Interface Sounds, Kenney, CC0. https://kenney.nl/assets/interface-sounds

What each file was before it was renamed:

| in this game | from | pack |
| --- | --- | --- |
| delivered_000 to 002 | impactSoft_medium_000 to 002 | Impact Sounds |
| missed_000 to 002 | impactPlank_medium_000 to 002 | Impact Sounds |
| pick_up | click_002 | Interface Sounds |
| throw | switch_004 | Interface Sounds |
| strike | error_004 | Interface Sounds |
| round_won | confirmation_001 | Interface Sounds |
| round_lost | error_008 | Interface Sounds |

These are stand-ins chosen by name and category rather than by ear. Anything
here can be replaced by dropping a different file into the sound bank; the game
picks at random from whatever list it finds, so a sound can also be given more
variants without touching any code.
